## 1. 요약

1. **"동일 문제" 정의는 사용자 해석이 맞다.** 같은 주제·유형·양식은 허용하고, 같은 *문제 사례*만 제외한다. 다만 "동일"은 문자열이 아니라
   다음을 포함해야 한다: 같은 그림(잘라내기·크기·색 변경·스크린샷 포함), 같은 문제 문장(바꿔 쓰기·번역·보기 순서·숫자만 바꾼 변형),
   같은 대상·사례에 대해 MMMU 정답을 결정하는 정보(같은 작품·환자 사례·분자). 같은 그림에 다른 질문도 제외한다(그 그림의 내용을 학습하므로).
2. **"보수적"은 정의가 아니라 처리 방식이었다.** 검출기 후보 중 **아직 안 본 것**을 일단 제외한 것이다. 실제 표본 232문항에서 중복 0건
   (95% 상한 1.3%)이지만, MMMU가 출처 목록을 공개하지 않아 출처만으로 무관함을 증명할 수 없으므로 검사는 생략할 수 없다.
   **MMMU test 정답이 2026-02-12 공개**되어 test도 val과 같은 누출 경로다(우리 제외 인덱스에는 이미 포함) `[검증]`.
3. **수만 문항 오염 검사는 계산이 아니라 검토 예산 문제다.** 3단계 분류(T1 자동 제외, T2 검토, T3 약한 신호)로 하면 검출기·임계값을 바꾸지 않고
   확장 가능하다. 단 T3를 "2단계 검증기 + 표본 감사"로 해제하는 것은 판정 절차 변경이라 **사용자 승인 필요**.
4. **생성기 제외 시 데이터 공급이 크게 줄어든다.** 라이선스가 확실한(CC-BY/CC0/MIT/CDLA) 기존 데이터만으로는 3,000문항 증명용 과목당 약 100개를
   **30과목 중 약 16과목**만 채운다 `[검증 요약]`. 과목당 1,000개 이상은 공급상 약 9–15과목만 가능하고,
   심리학·예술이론은 사실상 0, 약학·화학·기계·건축·마케팅·역사·문학·공중보건은 부족(내용 또는 수량)하다.
   → "수만 문항, 과목당 1,000"은 **"공급이 있는 과목만 1,000, 나머지는 있는 만큼 + 점검셋으로 하락 감시"**로 재정의해야 한다.
5. **"틀린 342문항만 다시 풀기"는 유효한 개선 시험이 아니다.** 학습 없이 다시 돌려도 표본 추출 무작위성 때문에 34–57문항(+3.8–6.3점)이
   "맞게" 바뀌고, 원래 맞던 558문항의 손실을 숨긴다 `[실측]`. **같은 900문항을 학습 전 모델(F0)로 다시 돌린 결과와 짝 비교**하고,
   seed 3개 이상(K≥3)이 필요하다(최소 검출 효과 K=1 3.4점, K=3 2.0점). 342 부분집합은 F0의 같은 부분집합과 나란히만 보고한다.
6. **비용 재추정**: 이전 "$17–19"는 학습만 1,500문항 기준이었다. 평가(900문항 1회 ≈ 25시간@동시2)를 넣으면 3,000문항 증명은
   약 **$40–62(동시16, 새 protocol·승인 필요) 또는 $115–132(동시2)**, 3만 문항 실전은 **약 $330–525(±50%), 3–5주** `[예측]`.
   모두 1단계 실측 처리량으로 다시 계산한다.
7. **Vision 경로**: 생성기 없이는 VISION_ON/OFF를 낼 관측 슬롯이 없다. 데이터셋 제작자가 만든 구조 주석(FinQA 표 셀+프로그램 피연산자,
   PGPS9K/Geometry3K 도형 논리식, MapQA 지도 메타데이터)으로 슬롯을 만들 수 있다 `[검증]`(구현·수용 검사 필요). 그 전까지는 Vision 동결
   (정답 검증 경로)로 진행한다.

## 3. "동일 문제" 판정 규칙 (권고안)

학습 문항 t, 벤치마크 문항 b(MMMU dev/val/test, MMMU-Pro standard/vision):

| 경우 | 판정 | 이유 |
|---|---|---|
| 같은 질문·같은 그림 | DUPLICATE | 정답 직접 노출 |
| 바꿔 쓰기·번역·전사 | DUPLICATE | 같은 사례·같은 정답. 문자열 검사로는 놓침 |
| 보기 순서 변경, 4지→10지(MMMU-Pro standard) | DUPLICATE | 정답 내용 동일 |
| 같은 그림·문장에서 숫자·단위만 바꾼 변형 | DUPLICATE | 풀이 경로가 같음(§2.2 금지 사항) |
| **같은 그림에 다른 질문** | DUPLICATE(가족 전체) | 그 그림의 사실을 학습함 |
| 같은 대상의 다른 사진(같은 작품·같은 MedPix 사례·같은 분자) | 정답이 그 대상 식별에 달리면 DUPLICATE, 아니면 DISTINCT, 불명확하면 UNRESOLVED | 판정자만 b 정답을 볼 수 있고 풀에는 기록하지 않음 |
| MMMU-Pro vision 스크린샷 | DUPLICATE | standard 문항의 전사 |
| 같은 유형을 독립적으로 쓴 문제(다른 테브난 회로, 다른 심방세동 ECG, 다른 모네 그림) | DISTINCT | 외부 학습 데이터가 주려는 일반 유사성 |
| 공통 상투구·빈 타일·축·로고만 겹침 | DISTINCT(검토자가 확인 후) | 문항 고유 내용 없음 |

DUPLICATE·UNRESOLVED는 가족(같은 이미지 해시 집합·같은 원 레코드) 전체를 제외한다. 이는 CLAUDE.md §2.2와 같고 더 완화하지 않는다.

## 4. 대규모 오염 검사 설계 (검출기·임계값 불변)

출처: MMMU는 "무료 온라인 자료, 퀴즈, 교과서"에서 수집했으나 과목별 출처 목록이 없다 `[검증]`. 위험 높은 풀 소스: Met·Cooper Hewitt(같은 작품),
VQA-RAD(MedPix), Geometry3K·AI2D·TQA(교과서·웹 도해), ChartQA(Statista/Pew). the_cauldron은 MMMU **test** 이미지만 제거했다 `[검증]`.
공개 학습 혼합물의 실측 중복: LLaVA-NeXT 데이터와 MMMU-val 이미지 2.67%·텍스트 3.56%, Cauldron/LLaVA-OV/Cambrian 2.15–3.05% `[검증]`.
대형 프로젝트(Llama 3, Keye-VL, FineVision 등)는 1–2개 신호의 높은 임계값으로 **자동 제거**하며 문항별 판정은 하지 않는다 `[검증]`.

| 단계 | 내용 | 승인 |
|---|---|---|
| 1. 샤드 스캔 | 4,000문항 이하 샤드(4,258문항에서 11.5GB 실측) + 전역 가족 전파, 기존 빌드와 후보 ID 동일 재현 확인 | 불필요(구현) |
| 2. 분류 | T1(정확 일치, pHash≤3, SSCD≥0.95, n-gram 포함률≥0.8): 검토 없이 가족 제외. T2(SSCD 0.75–0.95, SigLIP, OCR, 8-gram): 검토. T3(약한 타일 해시·5-gram만): 현재처럼 제외 | 불필요(현행 규칙) |
| 3. 부족 과목만 검토 | 데이터가 풍부한 소스(골수·DeepWeeds 등)는 표시되면 그냥 제외, 부족 과목의 T2만 검토 | 불필요 |
| 4. 벤치마크 기준 묶음 검토 | 벤치마크 기록 하나와 연결 후보를 한 장에 — 규모가 커질수록 절약 | 가벼운 확인(새 검토 protocol 버전) |
| 5. T3용 2단계 검증기 | 타일 SSCD, 국소 특징 RANSAC inlier, 타일 정보량을 증거로 기록, 모두 음성일 때만 자동 DISTINCT | **필요**(실제 대조 판정을 대체) |
| 6. 5의 보정 | MMMU 12,168장 × 약 8변환 + Pro vision↔standard 1,730쌍을 양성으로(비공개, training_allowed=false), 놓침 0건일 때만 채택(약 97k에서 상한 0.003%) | 5에 포함 |
| 7. 감사 | 자동 해제 층별 300개(0건 → ≤1%), 전체 3,000개(≤0.1%), 1건이라도 나오면 그 층은 수동 검토로 복귀. 무표시 문항 300개의 SigLIP 상위 이웃 5개 확인 | 불필요(검사 추가) |
| 8. 바꿔 쓰기 보정(LLM) | 텍스트 재현율 보정 | **필요**(외부 API·벤치마크 텍스트 취급) |

예측(4,258문항 실측의 선형 확장): 3만 문항 기준 OCR 약 26–45분, SSCD+SigLIP 약 25분, assemble 8샤드 약 2.5시간, 증거 약 15GB.
전수 AI 시각 검토는 약 2.2억 토큰(비현실적), 강한 신호만 약 5,300만 토큰. 수율: 검토 없음 약 23%(3만 확보에 원천 13만 필요),
강한 신호만 검토 약 41%(7.3만), 5단계 승인 시 약 30–32k 원천으로 가능. 3만 문항 중 0.1%가 놓친 중복이면 MMMU-val 영향 ≤0.26점(균등 가정, 낙관적).

## 6. RunPod 증명 평가 설계

| 항목 | 내용 |
|---|---|
| 비교 대상 | F0(학습 전 BF16 원본) **재실행** vs FT(학습 후 병합 BF16), 같은 GPU 종류·코드·protocol·동시성·seed 식. 저장된 B2 558/900은 F0 대용 불가(vLLM 비결정성) |
| seed | 3407 주, 3408·3409 반복 — 각각 사전 선언한 protocol 변형 ID(`mmmu-val-v8-seed3408` 등) |
| 1차 지표 | 900문항 엄격 V8 정확도 차이(seed 평균), 문항 단위 paired bootstrap 1만 회, 보조로 McNemar(seed 3407), FT arm ≤2개 Holm 보정 |
| 2차 지표 | 틀린 342의 회복 + 맞은 558의 유지(FT·F0 동일 실행에서), 공식 MMMU 채점기, Qwen 방식(판정기는 모델링, 실제 GPT 판정은 유료 API 승인 필요), 길이 잘림·최종답 누락 비율, 분야별 신뢰구간, 과목별 표 |
| 오염 민감도 | 학습 풀에 표시된 이웃이 있는 MMMU 문항 vs 없는 문항의 FT−F0 분리 보고(개선이 표시 문항에 몰리면 누출 의심) |
| 최소 검출 효과(α=.05, 검정력 80%) | 900 짝, K=1 3.4점 / K=3 2.0점 / K=5 1.5점; 342 대 F0 같은 342, K=1 20–30문항; 342 대 저장된 오답(무효) — 학습 없이 +34–57 예상 |
| validation 사용 한도 | arm당 체크포인트 1개만, 체크포인트·LR·데이터 선택에 val 사용 금지(비MMMU dev로만), 실행마다 해시 원장. 최종 측정은 MMMU-Pro Standard 10-way와 MMMU test(정답 공개되어 로컬 V8 채점 가능, 10,500문항이라 동시2 기준 arm당 약 290시간·$171 `[예측]`) |
| 정밀도 | NF4로 학습한 어댑터를 BF16에 붙이면 다른 함수 → RunPod에서는 `policy_precision: bf16`으로 학습(현재 CPU·mock 검사만, 1단계에서 실제 BF16 업데이트·재로딩 확인 필요) |
| 동시성 | 평가 동시성 2는 고정 조건. 비용 절감용 16은 새 protocol ID + F0 재실행 + **사용자 승인** 필요(§8.1) |

## 9. 사용자 결정이 필요한 항목

1. **"벤치마크라 칭하지만 학습 split이 있는" 데이터** 허용 여부(SSMR-Bench, ChEBI-20-MM, MMSci, Geometry3K, GVLQA, EXAMS-V). 권고: 제작자가 배포한 train split만 쓰고 val/test는 절대 사용하지 않는 규칙으로 허용.
2. **비상업(NC) 라이선스**(ScienceQA, TQA, TabMWP, STEM, HAM10000, DVQA, ELPV)를 수업 연구용 학습에 사용할지. 데이터·가중치 비공개 유지 전제.
3. **TAT-DQA PDF 래스터화**(제작자 PDF를 그림으로 변환, 내용 생성 없음, 새 의존성 pypdfium2).
4. **오염 판정 절차**: §4의 1–4·7단계 채택(승인 불필요)과, 5·6단계(T3 자동 해제용 2단계 검증기)·8단계(LLM 바꿔 쓰기 보정)의 승인 여부.
5. **Vision 경로**: (a) 증명은 Vision 동결, (b) 제작자 주석 슬롯 구현 후 일부 소스만 Vision 경로, (c) 소스별 고정 경로(엄격 라우팅 아님). 권고 (a)로 시작 + (b) 구현.
6. **실전 목표 재정의**: "과목당 1,000"을 공급 가능한 과목에만 적용하고 나머지는 있는 만큼 + 하락 감시로 둘지.

### 9.1 사용자 결정 (2026-10-30 저녁)

| 항목 | 결정 |
|---|---|
| 벤치마크 명칭 + train split 데이터 | **허용**(제작자 train split만, val/test 사용 금지). "현재 우리가 찾은 것들 위주로" |
| 비상업 라이선스·B등급 | 별도 선택 없음 → 해석: 현재 풀에 이미 있는 소스(ScienceQA·TQA NC, PlantVillage 등 B)는 유지, 새 NC 소스(STEM·HAM10000 등) 추가는 보류 |
| TAT-DQA PDF 래스터화 | 선택 없음 → 보류(차단 유지) |
| 오염 판정 | **분류 3단계만**(T1 자동 제외, 부족 과목 T2 시각 검토, T3 계속 제외). 2단계 검증기·LLM 보정은 사용하지 않음 → **2026-10-30 밤 사용자 추가 결정으로 갱신**: v3 실제 집계에서 T3 제외 시 경제·재무·화학·역사·수학이 거의 0이 되어 재질문, 사용자가 "부족 과목만 T2+T3 시각 검토(권장)"를 선택. 실제 적용 규칙 `tier-review-v1` = T2 전부 + 부족 과목(경제·재무·화학·역사·수학·물리·문학·임상·기초의학, 샤드3의 약학·CS)의 T3를 실제 이미지 대조(AI, human_verified=false), T1은 검토 없이 제외, 데이터 충분 과목의 T3만 검토 없이 제외. 자동 해제(2단계 검증기)는 여전히 미사용 |
| Vision 경로 | **Vision 동결로 시작 + 제작자 주석 슬롯 구현**(FinQA 표 전용, PGPS9K/Geometry3K, MapQA) |
| 실전 목표 | **공급 있는 과목만 1,000**, 부족 과목은 있는 만큼 + 과목별 점검셋 하락 감시, A급 추가 탐색 |
