# 런포드 증명 진행 보고 (2026-10-31, 한국어 원문)

> 화면에서 제 답변이 영어로 바뀌어 보이는 문제가 있어, 같은 내용을 이 파일에 한국어 원문으로 남깁니다.
> 이 파일은 제가 쓴 그대로이므로 번역·요약 없이 보입니다. 진행할 때마다 위쪽에 새 항목을 추가합니다.

## 현재 상태 (한국 시간 오후 9시경)

### 원격 대여 그래픽카드 (런포드)
- 대여기 `1rrqadukeabj2i` (A40, 시간당 0.59달러) — 프로그램 설치 중, 끝나면 1단계가 저절로 시작됩니다.
- 모델은 **원본 16비트(BF16)** 입니다. 4비트가 아닙니다.
  - 근거: 실행 명령의 `--policy-precision bf16`, 빠른 생성기 `dtype bfloat16`, 모델 적재 후 메모리 8.4GB(4비트면 약 2.5GB).
  - 원본 가중치는 고정하고, 덧붙인 작은 조정층(LoRA)과 시각 연결부(Merger)만 학습합니다.
- 오늘 쓴 돈: 약 1.8달러 / 남은 잔액: 약 48.5달러(추정). 쉬는 대여기는 즉시 지웁니다.

### 지금까지 확인된 것
- 노트북(4비트): 오답노트 파이프라인 전체(첫 풀이 → 정오 피드백 → 재시도 전 오류 점검 → 재시도 → 전체 이력 오답노트 → 독립 검증 → 갱신)가 돌아가고,
  가중치가 실제로 바뀌고, 저장 후 새 프로세스에서 같게 다시 불러와짐을 확인했습니다.
- 대여기(16비트): 설치·모델 적재·그래픽카드 점검·정답률 측정까지 확인했습니다.
  32문항을 4번씩 풀게 한 결과, 학습 신호가 있는 문항(4번 중 1~3번 맞힘)은 8개(25%)였습니다.

### 아직 확인되지 않은 것
- **대여기에서 16비트 가중치 갱신은 아직 한 번도 성공하지 않았습니다.** 지금 3번째 1단계가 이것을 확인합니다.

### "3,000문제 학습"의 실제 의미
- 후보 3,417문항을 모두 4번씩 풀게 해서, 가끔만 맞히는 문항만 학습에 씁니다.
- 항상 맞히거나 항상 틀리는 문항은 이 강화학습에서 가중치를 전혀 바꾸지 못합니다.
- 32문항 표본 기준(25%)이면 실제 학습 문항은 **약 850개**로 예상됩니다(추정).

### 다음 순서
1. 1단계: 16비트 갱신 → 저장 → 다시 불러오기 확인, 실제 학습 속도 측정
2. 파일럿: 3,417문항 정답률 측정(여러 문항 동시 생성) → 신호 있는 문항 선택 → 앞 300문항 학습
3. 본 학습: 신호 있는 나머지 문항(약 850개)
4. 평가: 예전에 틀린 342문항을 학습 전·후로 각각 3번 반복해 비교(V8 채점기)

1단계에서 속도를 재면, 2~4가 남은 돈 안에 들어가는지 다시 계산해 이 파일에 적겠습니다.

## 화면이 영어로 보이는 문제

- 저는 모든 답변을 한국어로 쓰고 있습니다. 화면에서 바뀌어 보이는 것은 프로그램 표시 단계의 문제로 보이며, 제가 설정으로 고칠 수 있는 부분을 찾지 못했습니다.
