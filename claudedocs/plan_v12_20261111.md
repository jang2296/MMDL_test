## v12 변경 (v11b 대비)
1. **보상 게이트 v7** (`single-t1-program-gate-v7`): accepted +1 / BARE_WRONG·NO_COMMITTED_ANSWER·LOOP −1 / TRUNCATED_NO_LOOP −0.5 /
   **REASONED_WRONG 0** / 새 판정 **CONTAINED_OPEN 0**(주관식, T1 INCORRECT, 정답의 단어열이 추출 답 안에 연속으로 들어 있음; 감점 종류보다 먼저 판정).
   CONTAINED_OPEN은 +1도 A1도 아니다. 다시 풀기에서 같은 경우는 지금처럼 정답이 아니다(A2 없음).
2. **교훈 누설 규칙 v2**: 정답의 글·어간과 보기 글자 언급은 계속 차단. 다른 보기의 어간은 차단하지 않되, 정답이 아닌 보기를
   (보기 수 − 1)개 이상 언급하면 소거 누설로 차단. 정답 탓 표현에 "error in the reference/answer/question", "grader misread" 추가.
3. **B 행**: 노트 필터를 통과한 노트는 다시 풀기 결과와 무관하게 B 후보(지금은 다시 풀기 정답일 때만). 가중치는 그대로(종류 합 0.05).
4. **H 행(사람 풀이 SFT)**: 데이터셋 참고 정보 중 사람이 쓴 풀이가 있는 출처(현재 hf-scienceqa의 lecture·solution)만.
   입력 = 평가와 같은 P0, 목표 = lecture(있으면) + solution + 최종 답 줄. 그 묶음의 해당 문항 전부(첫 풀이 정오 무관), 32토큰 이상.
   가중치 종류 합 0.10. 모델이 쓴 글이 아니므로 RL·재생 검사 대상이 아니다. 프로그램 생성 주석(CLEVR 장면 등)은 H에 쓰지 않는다.
5. **순서 v3**: 같은 3,500문항. 앞 구간을 풀이형 출처 중심 정원으로 결정적으로 재배열(규칙·seed·해시 고정, 정답·결과 미사용).
   정원과 묶음 수는 로컬 모의(L3: 출처별 생성 토큰·시간·비용)로 정해 계획 봉인 전에 이 문서에 기록한다.
   **확정(사용자 2026-11-11 "C안으로 진행")**: 70묶음 = 앞 1,116문항. 정원 scienceqa 316, geometry3k 200, ai2d 120, gvlqa 100, ssmr 90, ptbxl 90,
   nctcrc 60, chartqa 35, chebi-role 30, plantvillage 25, mapqa 20, clevr 15, slake 15(C안 1,120에서 scienceqa만 −4).
   파일 `mmdl-artifacts/self-note-single-20261105/v12/lot-v12/order-v3.json` sha256 `a6732f47…`, ids `5b873bbf…`(v10과 같은 3,500),
   pilot300 `419d7a3b…`, 정원 파일 `532fc402…`. 규칙: 출처별 기존 순서의 앞에서부터 정원만큼, 묶음마다 정원 비례로 결정적 배치(난수 없음).
   모의 비용(A40, 학습만): 8.5~10시간, 약 5~6달러.
6. 유지: 첫 4토큰 고정, KL β 0.02, 재생 검사, A1 0.05·A2 0.35(행당), 생성 1회씩, 길이 보정 2,048(LOOP 면제), 프로그램 검사만.
