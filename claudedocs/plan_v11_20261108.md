## v11 변경 (v10 대비)
1. **보상 게이트 v6 / 이점표** (`single-t1-program-gate-v6`, 기준선 없음): `reward`는 부호(+1/0/−1), `advantage`(float)는 아래 표.
   | 판정 | advantage |
   |---|---|
   | accepted(정답·32토큰 이상·정상 종료·반복/부정 없음) | +1.0 |
   | BARE_WRONG / NO_COMMITTED_ANSWER / LOOP (v9 그대로) | −1.0 |
   | REASONED_WRONG: 채점 대상(INCORRECT·INVALID_NO_FINAL·INVALID_MULTIPLE) + stop + 32토큰 이상 + 반복 없음 + 위 −1에 해당 안 함 | −0.5 |
   | TRUNCATED_NO_LOOP: 길이 한도 잘림, 반복 없음 | −0.5 |
   | 정답이지만 짧음·반복·부정·초과 길이, UNVERIFIABLE | 0.0 (정답은 절대 음수 아님) |
2. **PG**: term_i = −A_i · min(1, C/n_i) · Σ_t ℓ_{i,t} / (B·S), S = 1024(v9), **C = 2048**.
   - A_i > 0: ℓ = 저장 후보 분포 log q(v9 그대로, on-policy).
   - A_i < 0: ℓ = **원래 분포 log p**(log_softmax(logits), T=1, presence 없음, 전체 어휘). 후보 1개 위치의 0 기울기 제거. 같은 logits로 계산(추가 forward 없음).
   - C 선택 근거(v9 기록 모의, 토큰 가중 근사): C=2048 → 50% 질량 문항 129(≥100 기준), 양의 질량 48%(35~65% 기준), LOOP 몫 0.13(끝내기 신호 유지). C=1024는 LOOP 0.08로 약화.
   - 11-05 계획의 두 원칙(q 분포만 사용, 길이로 분모 불변)에 대한 **명시적 예외**로 protocol에 기록.
3. **노트 입력에 데이터셋 참고 정보**(정답 뒤, 노트 단계에서만): 출처별 허용 필드
   - hf-scienceqa: lecture, solution (사람 작성) · hf-clevr: program, scene(객체 목록으로 압축; 프로그램 생성) · hf-slake: modality, location, triple(자리표시 '_'만이면 생략) · hf-chebi-role: description, SMILES · hf-ptbxl: report, statements(보충 파일) · hf-ssmr: abc_context(보충 파일).
   - 앞 4개 출처는 이미 번들된 `source-provenance.json` annotations에 있음. ptbxl·ssmr은 원자료에서 만든 **보충 파일**(sha256 고정, 번들에 추가).
   - 4,000자 상한: 넘으면 뒤 필드부터 제외. 참고 정보는 MMMU/Pro와 13-gram 중복 검사(제외 신호로만) 후 사용.
   - 재풀이 입력·평가 입력(P0)에는 넣지 않는다. 기존 누설 검사 그대로.
4. **그대로 유지**: 첫 4토큰 F0 고정, KL β 0.02, 재생 검사·행 제외, SFT 가중(v10: A1 .05, A2 .35 행당, B .05), 생성 1회씩(T1·노트·재풀이), 프로그램 검사만.
5. **제외**: 자기증류, v10 출처 기준선, k>1, 정답 조건 교사.
