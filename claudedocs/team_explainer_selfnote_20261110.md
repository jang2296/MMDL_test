# 오답노트 자기학습 실험 정리

작성일 2026-11-10

Qwen3-VL-4B가 상위 모델 없이 스스로 쓴 오답노트로 학습해 MMMU 점수를 올리려는 실험입니다. 지금까지 가장 좋은 결과는 v11b의 552/900(8K 조건)으로 같은 조건 원본 541보다 11문항 높지만, 통계적으로 입증된 개선은 아직 없습니다.

## 목표와 규칙

목표는 지정 모델 Qwen3-VL-4B-Instruct의 MMMU validation 900문항 점수를 실제 파라미터 학습으로 올리는 것입니다. 기준점은 우리가 측정한 원본 558/900(62.0%, B2 조건·V8 채점)이고, 과제 지침의 공식 값은 67.4입니다.

| 규칙 | 내용 |
| --- | --- |
| 상위 모델 금지 | GPT·Gemini·Claude 같은 더 큰 모델의 풀이나 해설을 학습에 쓰지 않음. 튜터 모델도 금지 |
| 벤치마크 오염 금지 | MMMU·MMMU-Pro 문제와 그 변형은 학습에 쓰지 않음. 학습 자료 3,500문항은 13-gram 등으로 중복 검사 후 고정 |
| 답 하나 원칙 | 문항마다 답을 한 번만 생성. 여러 답 중 고르기(best-of-N, 다수결, 재순위) 금지 |
| 채점 고정 | 우리가 만든 V8 파서로만 채점. GPT 판정 없음 |
| 평가 1회 | 최종 모델마다 MMMU 900문항은 한 번만 평가 |
| 비용 | 런포드 48GB GPU, 시간당 1달러 미만. 안 쓰는 포드는 결과 회수 후 삭제 |

허용되는 것은 모델이 정답을 본 뒤 스스로 쓴 오답노트와, 자기 풀이 중 프로그램 검사를 통과한 것으로 하는 학습입니다.

## 현재 방법

![한 문항이 학습으로 바뀌는 흐름 · 5단계](team_explainer_selfnote_20261110_flow.png)

모델은 문항당 답을 한 번만 내고, 틀리면 정답을 본 뒤 스스로 오답노트를 씁니다. 다시 풀 때는 교훈만 보이고 정답은 보이지 않으며, MMMU 평가 입력에는 노트도 정답도 넣지 않습니다. 학습 행은 사람이나 AI의 내용 검토 없이 프로그램 검사(정답, 정상 종료, 반복 없음, 정답 누설 없음)만으로 받습니다.

## 시도 이력과 결과

네 가지 방식을 거쳐 지금의 '단일 응답 RL+SFT 오답노트'에 왔고, 아직 원본을 확실히 넘은 버전은 없습니다. 비교는 같은 평가 조건끼리만 합니다(원본은 8K 조건 541, B2 조건 558).

| 시기 | 버전 | 핵심 아이디어 | MMMU 900 | 판정 |
| --- | --- | --- | --- | --- |
| 11-10~ | v11c (진행 중) | v11b 156묶음 체크포인트에서 남은 1,008문항 이어 학습 | 8K 평가 예정 | — |
| 11-08~09 | v11b | 모든 오답 첫 풀이에 감점(−1/−0.5), 노트에 데이터셋 해설 제공, 반복 감점 강화 | 552 (8K) | 원본 대비 +70/−59, p 0.38. 학습 모델 중 최고, 개선은 미입증 |
| 11-08 | v11 | v11b와 같으나 반복 감점이 약함 | 미평가 | 22묶음에서 잘림 정지 규칙 발동 |

| 11-03 | 오답노트 2판 | 고쳐 쓴 풀이 대신 교훈만 보고 다시 풀기, 맞은 풀이만 SFT | 544 (8K) | 원본 대비 +3, p 0.86 |

| 10-04~12 | 일반 지도학습 (G6, TabMWP) | 공개 데이터의 답을 그대로 학습 | MMMU 60문항: 36 → 21~27 | 네 조건 모두 하락 |

8K는 답 길이 8,192토큰과 작은 이미지, B2는 32,768토큰과 Qwen 공식 이미지 크기입니다. 11-09부터는 시간과 비용 때문에 8K로 평가하고 같은 조건 원본 541과 문항별로 비교합니다.

## 겪은 문제와 교훈

가장 반복된 문제는 '풀이 없이 답만 내는 쪽으로 무너지는 것'과 '서로 다른 평가 조건의 점수를 비교한 것'입니다.

| 분류 | 문제 | 어디서 | 대응과 교훈 |
| --- | --- | --- | --- |
| 모델 행동 | 풀이 없이 답만 내는 쪽으로 무너짐 | v3 시험(풀이 170→4토큰), v4(32토큰 미만 28%→44%), v8 | 맞은 답만 보상하면 짧은 답이 유리해짐. 32토큰 미만 정답은 0점, 짧은 오답은 −1, 첫 4토큰 원본 고정, 출처별 단답 비율 감시 |
| 모델 행동 | 끝없이 생각하다 8,192토큰에서 잘림 | 원본 111/900, v11은 22묶음에서 정지 | 반복한 풀이에 강한 감점(v11b) → MMMU 잘림 111→70 |
| 모델 행동 | 노트가 진짜 실수를 잘 못 찾고, 교훈에 정답을 그대로 씀 | 노트의 약 25%가 정답 누설로 걸러짐, 교훈 재풀이 정답 약 30% | 누설 필터, 노트에 데이터셋 해설 제공(v11). 효과는 제한적 |
| 모델 행동 | 정답이나 채점기를 탓하는 노트 | v11b 노트 약 3% | 1건이 필터를 통과해 학습됨. 필터 보강 필요 |
| 채점 | 학습용 채점기가 긴 풀이를 '답 여러 개'로 오판, 문장·단위 답을 오답 처리 | v3, v6, v11b | 평가와 같은 V8 기준으로 맞춤. 남은 거짓 오답은 다음 수정 후보 |
| 데이터 | 학습 자료와 MMMU 과목이 다름 | MMMU 13과목은 자료 0, 이 과목이 원본 오답의 46% | 규칙 안에서 구할 수 있는 출처가 적음. 자료 있는 과목도 오르지 않아 자료만으로는 부족 |
| 평가 설계 | 서로 다른 조건의 점수를 비교 | v2 544(8K)를 B2 558과 비교해 '실패' 판정. 같은 8K 원본 대비로는 +3 | 같은 조건 원본과 문항별 비교로 통일 |
| 인프라 | 호스트 오류, 정지한 포드 재시작 실패 | GPU 드라이버 오류, 재시작 여러 번 실패 | 재시작이 안 되면 삭제 후 새 포드 |
| 인프라 | 32K 평가가 느림 | A40에서 초당 약 145토큰, 900문항에 약 8시간 | 8K 평가로 전환(약 1시간) |
| 비용 | 평가 도중 자금 소진 | v9 평가가 622/900에서 중단 | 학습 전에 평가 비용까지 예산 확보 |
| 운영 | 노트북 절전으로 로컬 감시 중단 | v11b 2시간 공백, 정지 규칙 발동을 늦게 발견 | 감시를 포드 안에서 실행, 발동 시 자동 정지 |
| 운영 | 결과 회수 때 부모 체크포인트 정보 누락 | v11b를 같은 코드로 이어 학습할 수 없음 | 이어 학습용 새 코드(v11c), 회수 범위 보강 |

## 왜 크게 오르지 않는가

v11b가 얻은 +11문항은 전부 '원본이 8,192토큰에서 잘리던 문항을 끝까지 푼 것'에서 나왔고, 추론 자체는 좋아지지 않았습니다.

| 원본 답 길이 구간 | 문항 수 | 원본 정답 | v11b 정답 | 차이 |
| --- | --- | --- | --- | --- |
| 8,192토큰에서 잘림 | 111 | 2 | 21 | +19 |
| 512토큰 이상 | 305 | 188 | 186 | −2 |
| 32~511토큰 | 448 | 326 | 320 | −6 |
| 32토큰 미만 | 36 | 25 | 25 | 0 |

- **학습 신호가 약합니다.** 노트가 실제 오류 원인을 드물게 찾고, +1을 받는 풀이는 대부분 원래 맞히던 문제입니다.
- **모델이 거의 안 바뀌었습니다.** 원본에서 벗어난 정도(KL)가 토큰당 약 0.0002입니다. 붕괴를 막는 장치(KL, 첫 토큰 고정)가 변화 폭도 제한합니다.
- **학습한 파라미터:** LLM 조정층 3,300만, 시각-언어 연결층 전체 1억 900만, 시각 조정층 240만. 전체 44억의 약 3.3%이며 평가 때는 하나로 합쳐 씁니다.
- **학습 문제와 MMMU가 다릅니다.** 차트·지도 읽기 위주인 학습 자료와 대학 전공 지식을 묻는 MMMU 사이에 격차가 큽니다.
- **큰 방법이 규칙상 막혀 있습니다.** 상위 모델 풀이 학습과 여러 답 중 고르기가 금지라, 내부 분석은 현실 범위를 약 557~578(B2 기준)로 봅니다.

평가는 1회라 결과가 ±14문항 안팎 흔들립니다. +11은 그 범위 안입니다.

## 지금 진행 중과 다음 단계

11-10 01:54Z(한국시간 10:54)부터 v11c가 v11b의 156묶음 체크포인트에서 남은 63묶음(1,008문항)을 이어 학습하고 있습니다. 런포드 A40, 시간당 0.59달러입니다.

1. **이어 학습:** 학습 방식·보상·데이터 순서는 v11b 그대로입니다. 새 코드는 156 체크포인트를 해시로 봉인해 불러오는 부분뿐입니다. 약 7.5시간 예상입니다.
2. **자동 정지 규칙:** 포드 안 감시가 풀이형 문제의 단답 비율 10% 이상, 최근 풀이 중앙값 120토큰 미만, 잘림 급증 등을 보면 스스로 학습을 멈춥니다.
3. **평가:** 학습이 끝나거나 멈추면 그 시점 체크포인트로 MMMU 900을 8K 조건으로 1회 평가하고, 원본 541과 문항별로 비교합니다.
4. **결과 정리:** v11c 결과를 v11b 계열의 최종으로 미리 정했습니다. 552와 두 값을 모두 보고하고, 더 높은 쪽을 고르지 않습니다.

기대치는 552에서 +5~15문항이고 65점(585)에 닿을 근거는 없습니다. 다음 버전에서 고칠 후보는 정답 탓 노트 필터, 문장·단위 답 채점, 심전도 노트 누설 필터입니다.

## 용어와 근거 문서

| 용어 | 뜻 |
| --- | --- |
| T1 | 정답을 보여주지 않고 모델이 처음 푼 풀이 |
| V8 파서 | 우리가 만든 최종 답 추출·채점기 버전 8. 원본 558점도 이 기준 |
| B2 / 8K | 평가 조건. B2는 답 길이 32,768토큰과 공식 이미지 크기, 8K는 8,192토큰과 작은 이미지 |
| 묶음(block) | 16문항. 묶음마다 가중치를 한 번 갱신. 3,500문항 = 219묶음 |
| RL (강화학습) | 모델 자신의 풀이에 점수(+1, −0.5, −1)를 주어 그 풀이가 나올 확률을 올리거나 낮춤 |
| SFT (지도학습) | 프로그램 검사를 통과한 자기 풀이·노트를 그대로 따라 쓰게 학습 |

| 문항별 비교 (McNemar) | 같은 900문항에서 새로 맞힌 수와 새로 틀린 수를 비교하는 검정. p가 0.05보다 크면 우연과 구분 불가 |
