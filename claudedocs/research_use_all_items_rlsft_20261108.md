## 3. 방법 조사 결과

### 먼저 정할 것 — §2.1 해석

§2.1 원문: "틀린 풀이는 입력에만 두고 손실에서 제외한다." `[AI 판단]` 우리는 이를 "틀린 풀이를 **정답처럼 따라 쓰는 학습(양의 목표)**의 금지"로 읽어 왔다. 그래서 v9는 이미 형식 실패 77행과 맨답 내용 오답 46행에 −1을 준다. 사용자가 승인한 v10(11-07, 출처별 기준선)도 추론한 오답에 음의 이점을 준다. 그러나 "틀린 풀이 토큰에 어떤 손실도 걸지 않는다"로 읽으면 아래 3.1·3.5·3.6·3.8·3.12가 모두 막힌다. **사용자 확인이 필요하다(Q0).**

### 3.1 음의 표본 강화(NSR / W-REINFORCE) — 추론한 오답에도 감점
- 틀린 첫 풀이의 확률을 낮춘다. 기준선·그룹이 필요 없어 표본 1개에 바로 쓸 수 있다.
- 쓰는 문항: 추론한 오답 237, 반복 없는 잘림 25, 보상 0 복수답 3(합 265). 추가 생성 없음.
- 근거: Zhu et al., arXiv:2506.01347 (NeurIPS 2025). Qwen2.5-Math-7B·Qwen3-4B·Llama-3.1-8B, MATH 7,500문항, **프롬프트당 rollout 8**, 전체 미세조정. Qwen2.5-Math-7B Pass@1: 기저 63.2 / PSR 74.1 / NSR 75.7 / W-REINFORCE 76.6 / GRPO 76.3. Qwen3-4B: NSR 94.0 vs GRPO 93.9.
- 위험: 표본 8개 조건이라 표본 1개 근거가 없다. 긴 오답 안의 맞는 중간 단계도 내려간다. 음의 질량 비율이 0.47→0.76으로 커진다 `[모의]`. 짧은 정답이 "안전지대"가 되어 쏠릴 수 있다. NSR 단독 장기 학습 뒤 하락 보고가 있다.
- 태그: **NEEDS USER DECISION**(Q0·Q1). 11-05 계획 §6.2 "음의 오답 보상은 현재 안에 넣지 않는다"는 고지도 있었다.

### 3.2 확신 오답의 0 기울기 복구 — 음의 행만 원래 분포에서 계산
- 음의 행에 한해 잘린 분포의 log q 대신 원래(T=1, 전체 어휘) log p 또는 unlikelihood −log(1−p)를 쓴다(둘 중 하나를 사전 고정).
- 쓰는 문항: 기울기 0이던 23행(맨답 오답 22, 정답 1) + 모든 음의 행의 후보 1개 위치. 추가 생성·추가 forward 없음(단 행동 토큰의 원래 logit 수집 코드는 새로 필요).
- 근거: unlikelihood(Welleck et al., arXiv:1908.04319, 2019). 추론 과제에서 답 구간 한정 unlikelihood의 공개 결과는 찾지 못했다(미검증).
- 태그: **ALLOWED, 단 11-05 계획 §6.2 "RL은 실제로 표본을 뽑은 분포 q로 계산" 원칙의 명시적 예외로 protocol v11에 기록하고 사용자에게 알린다.** 기존 −1 행(123)에만 적용하면 Q1과 무관하다.

### 3.3 행별 토큰 상한 — 긴 반복 행의 질량 독점 완화
- 행 기여를 min(1, C/n_i)로 눌러 한 행이 최대 C토큰어치만 반영되게 한다. 행 평균으로 바꾸면 50%/90% 질량 문항이 37/348 → 209/538 `[모의]`.
- 근거: Dr. GRPO, arXiv:2503.20783 (2025) — 길이 편향이 틀린 응답을 길게 만든다는 지적.
- 위험: MMMU로 전이된 유일한 효과(끝내기)를 만든 긴 반복 −1 신호가 약해진다.
- 태그: **ALLOWED, 단 11-05 계획 l.183 "응답 길이로 분모를 바꾸지 않는다" 원칙의 예외로 기록.** C는 평가 전 숫자 하나로 고정하고, 8192 도달 비율에 수치 정지 문턱을 둔다.

### 3.4 표본 1개용 기준선(묶음 평균 / 출처별 고정표 v10 / 문항별 과거 성공률)

- 위험: **정답이지만 보상 0인 행(476)을 음수로 누른다.** v10 고정표 모의: 정답·검증 불가 367행이 음수, 음의 질량 81.8% `[모의]`. v7 원칙("맞은 답은 내리지 않는다")과 충돌. 11-07 v10 승인 당시 이 점은 설명되지 않았다.

### 3.5 교훈 조건 자기증류(OPSD/SDPO 방식, 피드백 = 자기 교훈)
- 교사 = 동결 F0에 "P0 + 누설 검사 통과 교훈"을 넣은 것, 학생 = 현재 정책에 P0만. 이미 생성된 첫 풀이 토큰을 두 문맥에서 teacher-forcing으로 읽혀 위치별 KL(교사‖학생)을 준다. 새 글 생성 없음, 교훈 문항당 no-grad forward 1회.
- 쓰는 문항: 교훈 수용 277문항(재풀이 실패 175 포함).
- 근거:
  - OPSD, Zhao et al., arXiv:2601.18734 (2026): Qwen3-1.7B/4B/8B, **문항당 rollout 1**, LoRA. v3 4B 평균 61.2 → OPSD 63.6 (GRPO 62.7, SFT 58.6). v1에서는 4B 48.3 → 50.6(GRPO 49.6, **GRPO 8 rollout 대 OPSD 1 rollout**). 단 교사가 본 특권 정보는 **외부에서 만든 참조 풀이 전체**라 우리는 쓸 수 없다.
  - SDPO, Hübotter et al., arXiv:2601.20802 (ICML 2026): Qwen3-8B·Olmo3-7B, 재채점만(생성 추가 없음). 피드백은 성공 표본·환경 출력. 응답 길이가 3배 이상 줄었고, 0.6B~1.5B에서는 GRPO보다 낮았다.
  - 비판, Harne et al., arXiv:2608.04794 (2026): 특권 정보 교사 자기증류를 **단독 목적함수**로 쓰면 어려운 과제에서 정확도가 정체·하락한다.
  - RLCSD arXiv:2606.11709: 교사-학생 log-prob 차가 스타일 토큰에서 과제 토큰의 약 3배(모델 미명시).
- 위험: 교훈의 25%가 누설로 거부됐으니 통과한 교훈도 방향을 암시할 수 있다. 교훈 재풀이 정답률이 36.8%라 교사가 학생보다 낫다는 보장이 없다. 길이 단축(SDPO)은 v4 실패 방향이다. 교훈 내용 정확성은 11-05 결정상 미검증이다.
- 태그: **NEEDS USER DECISION(Q2), 권장 보류.** (1) 11-05 "학습 행 수용은 정답 조건이 있는 프로그램 검사만"인데 277 중 175는 재풀이도 틀렸다. (2) 11-02는 교훈 기반 행동을 "V8 정답 재풀이"일 때만 학습하게 했다. (3) 틀린 첫 풀이 위치마다 교사 분포를 목표로 거는 손실이라 §2.1과 회색 지대다(Q0). 허용 가능한 축소안: **재풀이가 V8 정답인 102문항으로 한정 + 답 구간 마스크 + PG 병행.** 채택 전 교훈 표본 AI 검토(오류율) 보고를 먼저 한다.

### 3.6 성공 재풀이를 교사 문맥으로
- 교사 = F0(P0 + 자기 정답 재풀이), 학생 = P0. 첫 풀이 토큰을 재채점한다. 102문항. 추가 생성 없음.
- 위험: 교사가 답 구간에서 정답에 질량을 몰아 사실상 라벨 SFT가 될 수 있다. 재풀이의 34%는 형식 교정이다.
- 태그: **NEEDS USER DECISION(Q2에 합침).** 재풀이는 정답 없이 쓴 자기 글이라 11-02 금지 대상은 아니지만, 11-02가 허용한 것은 A2 지도학습뿐이다.

### 3.7 정답 조건 교사 / 노트 전문 교사 / 정답 확률 보상(VeriFree·RLPR·NOVER)

## 4. 권장 설계 — v11 손실(결정에 따라 갈라짐)

문항 i(묶음 B=16), 첫 풀이 토큰 n_i개, 분모는 v9와 같이 고정 B·S(S=1024).

**(1) 정책기울기** — 행별 토큰 상한 C(사전 고정, 출발값 1024):
```
L_PG = −Σ_i A_i · min(1, C/n_i) · Σ_t ℓ_{i,t} / (B·S)
```
- A_i = +1: 정답, A1 수용(640). ℓ = 저장 후보 분포 log q(지금과 같음).
- A_i = 0: 정답인데 짧은 답·반복·초과 길이·답 부정(476), 검증 불가(28). 의도적 0.
- A_i = −1: 맨답 오답·최종답 없음·복수답·반복 잘림(123). **ℓ = 원래 분포 log p**(3.2, 0 기울기 23행 복구).
- A_i = −λ_neg(**Q0·Q1 승인 시**): 추론한 오답 237, 반복 없는 잘림 25, 보상 0 복수답 3. λ_neg = 0.5 사전 고정. Q1이 "답 구간만"으로 승인되면 V8이 추출한 최종답 토큰에만 건다.

**(2) KL·첫 4토큰 고정항, (3) A1 0.05 / A2 0.5 / B 0.05, 재생 제외** — v9 그대로.

**(4) 교훈 조건 자기증류** — Q2 승인 시에만, 102문항(재풀이 V8 정답) 축소안부터. 위치 0~3·최종답 구간 마스크, 행별 상한, PG와 병행. 계수 c_SD는 CPU/로컬에서 자릿수만 확인하고, 최종값은 런포드 첫 4묶음 검증 주기에서 고정한다.

**(5) 기준선** — Q7 결정 전까지 보류.

**(6) 감시 문턱(사전 등록)**: 첫 풀이 중앙값 ≥120토큰, 전체 32토큰 미만 비율 ≤0.35, **출처별** 32토큰 미만 비율이 0~5묶음 대비 +0.20 이하(v8 교훈), 8192 도달 비율이 v9 구간값의 2배 이하, 최종답 없음 비율이 v9 구간값의 2배 이하. 하나라도 어기면 정지 후 보고.

**과제 기울기 문항 수(모의, 효과 근거 아님)** `[모의]`:

| 결정 | 기울기를 받는 문항 | KL만 |
|---|---|---|
| v9 그대로 | 805 (52.5%) | 727 |
| Q1 승인 | 1,028 (67.1%) | 504 |
| Q1 + Q2(277 전체) | 1,028 (교훈만 있는 137문항이 모두 Q1 안) | 504 |
| Q2(277)만 | 942 (61.5%) | 590 |

- Q1을 승인하면 Q2는 문항 수를 늘리지 않는다. Q2의 가치는 신호의 밀도(토큰 단위 방향)뿐이다.
- **MMMU 효과의 근거는 없다.** 음의 보상은 끝내기 신호를 키울 수 있다(잘림 25행 추가). 내용 정확도 개선 근거는 우리 조건의 문헌에 없다. 900문항 1회로 개선을 주장하려면 같은 규약 F0 대비 순 +22~+27이 필요하다. ±2점이 현실적이다.

**v4 붕괴와 다른 점**: v4는 음의 보상 없이 정답 370행만 +1과 A1로 두 번 밀어 올렸다. v11은 짧은 정답을 올리지도 내리지도 않고, 음의 질량이 한 행에 몰리지 않게 하며, 출처별 쏠림 감시를 둔다. 단 v9도 쏠리지 않았으므로(.285→.301) 이것이 재발 방지를 증명하지는 않는다.

### 6.2 v9 기록 모의(모델 없음)
- v11 보상·상한으로 PG 질량 재계산. 사전 기준: 50% 질량 문항 ≥ 100(v9 37), 양의 질량 비율 35~65%, 정답 행 음의 이점 0건, 기울기 0 행 23 → 0.

### 6.3 로컬 RTX 5060 NF4 추론 전용(Q2 승인 시)
NF4는 BF16과 분포가 다르므로 같은 NF4 안의 상대 비교만 쓴다.
- **교훈 신호 시험(수정판)**: Δ = log π_F0(재풀이 | 교훈+P0) − log π_F0(재풀이 | P0). 재풀이는 교훈 문맥에서 뽑힌 글이라 Δ가 양수인 것은 구성상 당연하다. 그래서 **정답 재풀이 102건과 실패 재풀이 175건의 Δ 분포를 비교**해 정답군이 유의하게 큰지를 본다. 첫 풀이 토큰에서도 Δ를 재서, 답 구간 밖에서 교사가 어느 방향으로 움직이는지 본다. 결과는 인과가 아니라 상관으로 보고한다.
- 신호 위치: 교사-학생 차이가 큰 토큰의 70% 이상이 답 구간 밖이어야 한다(안에 몰리면 누설 신호로 보고 폐기).
- 스타일 쏠림: 차이 상위 토큰 중 구두점·접속어 비율을 보고한다.
