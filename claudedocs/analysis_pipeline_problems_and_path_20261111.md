## 4. 파이프라인의 문제 (중요도 순)

### 문제 1. 추론을 고치는 재료가 거의 만들어지지 않는다 `[실측]`

| 단계 | 수 (2,700문항) |
| --- | --- |
| 첫 풀이 오답 → 노트 작성 | 897 |
| 누설 검사 통과 | 627 |
| 교훈 보고 다시 풀어 정답 | 227 |
| 학습에 채택된 A2 | **171** (chartqa 63, mapqa 28, slake 24, geometry3k 21, ssmr 17, 그 외 18) |

- 추론형 출처에서 나온 A2는 약 60개뿐이다. 156번 갱신 동안 평균 2~3묶음에 하나다.
- **교훈이 정말 도움이 됐는지도 모른다.** 같은 문제를 교훈 없이 다시 풀게 한 대조군이 없다. 생성에 무작위성(temperature 0.7)이 있어서,
  교훈 없이 다시 풀어도 일부는 맞는다. A2의 일부는 '교훈 덕분'이 아니라 '다시 뽑아서 맞은 것'일 수 있다 `[가설]`.
- AI 정독 판단으로는 노트가 진짜 오류 원인을 짚는 경우가 드물다. 4B 모델은 정답과 해설을 보여줘도 자기 풀이의 어느 줄이 틀렸는지 잘 찾지 못한다.

### 문제 2. 감점 신호가 짧은 답 쪽으로 민다 `[실측 + 가설]`

- v11에서 '성실히 풀었지만 틀림'에 −0.5를 넣었다. 대상은 588행으로, 감점 행 중 가장 많다.
  긴 풀이일수록 토큰이 많아 더 많이 깎인다. 모델이 택할 수 있는 가장 쉬운 대응은 풀이를 줄이는 것이다.
- 주관식에서 내용은 맞지만 표현이 긴 답 78건이 오답 처리되어 −0.5(63건)나 −1(15건)을 받았다.
  예: 정답 "Chile" ↔ 답 "the country with the highest share … is chile".
- 실제로 풀이형 출처의 첫 풀이 길이가 줄었다. geometry3k 666 → 710 → 414, ssmr 2,068 → 1,429 → 789, gvlqa 368 → 249 → 215토큰(초반 → 중반 → v11c).
- MMMU에서도 같은 방향이다. 풀이 길이 중앙값 444 → 357 → 349.5, 원본이 512토큰 이상 쓰던 305문항 188 → 186 → 183.

### 문제 3. 학습 자료가 MMMU와 다르다 `[실측]`

- 학습 2,700문항 중 ChartQA 650 + MapQA 450 + SLAKE 216 = 1,316문항(49%)이 값 읽기·한두 단어 답이다.
  이 출처들의 32토큰 미만 단답은 대부분 정답이라(524/643) 계속 0점 또는 칭찬 없이 지나가고, 추론 연습이 되지 않는다.
- MMMU 30과목 중 13과목은 학습 자료가 없다. 자료가 있는 과목도 오르지 않았다.
- MMMU는 객관식 94%인데 학습 자료의 주력 출처는 주관식이다.

### 문제 4. 분류형 문제는 오답노트 단계가 사실상 꺼져 있다 `[실측]`

누설 필터가 보기에 나온 단어 전체를 막아서, 심전도 87개 중 7개, 조직 사진 64개 중 8개, 식물 19개 중 2개만 통과했다.
이 출처들은 틀려도 감점만 받고 '어떻게 고칠지'는 배우지 못한다.

### 문제 5. 붕괴 방지 장치가 변화 폭도 막는다 `[실측]`

- 실측 가중치 변화: 언어 모델 36층 0.13~0.19%, 연결층 0.36~0.45%, 시각 인코더 0.03%. 출력 분포 변화(KL)는 토큰당 약 0.0002.
- 학습률이 219묶음에서 0이 되도록 줄어든다. v11c의 13묶음은 최고 학습률의 30% 이하에서 돌았다.
- 다만 변화를 키우면 v4·v8처럼 무너진 전례가 있다. **브레이크를 푸는 것보다 미는 방향을 고치는 것이 먼저다.**

### 문제 6. 좋아졌는지 판단할 수단이 약하다 `[실측]`

- 1회 평가 흔들림이 기대 효과(+5~15)와 같은 크기다.
- 학습 중 감시 규칙이 출처 구성을 보정하지 않아 두 번 모두 애매한 근거로 멈췄다(v11b 차트 단답, v11c 짧은 답 출처 유입).
- 교훈 효과, 감점 효과를 따로 재는 대조 실험이 없다.

## 5. 개선 방안 — v12 설계

규칙은 그대로 지킨다: 상위 모델의 글을 학습하지 않음, MMMU·MMMU-Pro 자료 미사용, 문항당 답 하나, V8 채점, 자기증류 미사용(11-08 결정).

### 5.1 미는 방향 바로잡기 (11-10 사용자 결정 반영)

| 변경 | 내용 | 기대 |
| --- | --- | --- |
| 감점표 정리 | 반복·잘림·답만 쓴 오답·최종답 없음은 감점 유지. **성실한 오답 −0.5 → 0** | 풀이 축소 압력 제거. 잘림 해소 효과는 유지 |
| 장황한 정답 | 정답 표현이 답 안에 있으나 V8과 불일치하면 **0점**(칭찬도 감점도 없음) | 맞은 추론 78건의 감점 제거 |
| 누설 필터 | 보기 전체 단어 대신 정답 단어와 정답 단정 문장만 차단 | 분류형 출처에서 노트·다시 풀기 재개 |

### 5.2 문항을 버리지 않고 쓰는 방법

지금 각 문항이 학습에 기여하는 방식과 바꿀 점은 다음과 같다.

| 문항 결과 | 지금 | v12 제안 | 규칙 |
| --- | --- | --- | --- |
| 첫 풀이 정답, 성실한 풀이 | +1과 A1 | 유지 | 허용 |
| 첫 풀이 정답, 단답 | 0점, 학습 없음 | 유지(짧은 답을 강화하지 않기 위함) | 허용 |
| 오답 → 교훈 보고 정답 | A2 + B | 유지. A2 비중을 추론형 출처 중심으로 | 허용 |
| 오답 → 다시 풀어도 오답 | 감점만 | **노트(B)만 학습**하고 첫 풀이 감점은 5.1대로 | 허용 |
| 오답, 노트가 필터에 걸림 | 감점만, 노트 버림 | 필터 수정으로 대부분 구제 | 허용 |
| 반복·잘림 | 감점 | 유지 | 허용 |

추가로 검토할 수 있지만 결정이 필요한 방법:

- **데이터셋의 사람 풀이를 직접 학습**: ScienceQA의 강의·풀이처럼 사람이 쓴 해설을 따라 쓰게 하는 지도학습이다.
  상위 모델의 글은 아니지만 '자기 글만 학습한다'는 설계에서 벗어난다. 추론 내용을 직접 가르칠 수 있는 거의 유일한 재료다. **사용자 결정 필요.**
- **정답 글자만 학습**(자기 풀이 뒤의 최종 답 토큰에만 손실): 오답 문항을 전부 쓸 수 있지만, 답만 가르친 G6가 MMMU를 낮춘 전례가 있어 권하지 않는다.
- **무교훈 대조 다시 풀기**: 학습에는 쓰지 않고 교훈 효과만 재는 진단이다. 11-05의 '무교훈 대조 제거' 결정을 되돌려야 한다. **사용자 결정 필요.**

### 5.3 자료 구성 바꾸기

이미 오염 검사를 통과한 3,500문항 안에서 순서와 비중만 바꾼다(새 자료 없음, 새 순서 해시 필요).

- 값 읽기 출처(ChartQA·MapQA·SLAKE 단답형) 비중을 줄이고, 풀이가 필요한 객관식 출처(ScienceQA·AI2D·Geometry3K·GVLQA·SSMR·ChEBI·PTB-XL)를 앞에 둔다.
- 근거: MMMU는 객관식 94%이고, 값 읽기 문항은 추론 재료를 만들지 않으면서 단답 쏠림을 만든다 `[실측]`. 효과 크기는 미검증이다.
- 남은 예산으로는 약 100묶음(1,600문항)만 돌릴 수 있으므로 앞 100묶음의 구성이 곧 학습 내용이 된다.

### 5.4 감시와 평가

- 감시 규칙을 출처별 초반 기준과 비교하도록 바꾼다. 짧은 답이 정상인 출처가 섞여도 오정지하지 않게 한다.
- 결정용 평가는 seed 3개 평균을 권한다(8K 기준 약 3시간, 약 2달러). 'MMMU 1회' 규칙과 충돌하므로 **사용자 결정 필요.**
- 최종 보고용 1회는 B2 조건이 원본 558과 직접 비교된다(A100 80GB 약 3시간, 약 4~5달러, GPU 규칙 예외 승인 필요).

### 5.5 바꾸지 않는 것

- 첫 4토큰 고정, KL, 재생 검사, 문항당 생성 1회씩. 붕괴를 막은 장치들이고 한 번에 여러 요인을 바꾸면 원인을 가릴 수 없다.
- 학습률 스케줄은 100묶음 실행에 맞춰 총 단계 수만 조정한다.
